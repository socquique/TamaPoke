# Cardputer ADV Port Branch

This branch is an unofficial M5Stack Cardputer ADV port of the original TamaPoke project.

Original developer: **socquique**

Original repository: https://github.com/socquique/TamaPoke

The original TamaPoke pet engine, game design, Pokedex data and core project remain credited to the original developer.

Cardputer-specific work on this branch includes the 240x135 UI adaptation, keyboard navigation, low-memory sprite streaming, display buffering and Cardputer persistence.
