# TamaPoke Cardputer ADV v0.7

> This is an unofficial Cardputer ADV **port** of the original **socquique/TamaPoke** project.
> Original project: https://github.com/socquique/TamaPoke
> Credit for the original TamaPoke game, pet engine, and core project belongs to its original developer.


First public Cardputer ADV release.

## Major features

- Clean Cardputer adaptation of the TamaPoke habitat/menu UI
- Full-screen buffered rendering
- Cardputer arrow-key navigation and direct Esc/back support
- Larger crisp Pokémon rendering
- 151-species PMD TPK2 streaming from microSD
- Pokédex, profile, stats, medals and progression screens
- Feeding, bathing, sleeping, evolution, farewell and release flows
- Pokéball minigame and strength training
- Automatic two-slot microSD persistence

## Required SD files

This release does not contain Pokémon sprite assets.

Place the generated `/mons` folder at the root of the microSD before starting.

## Save format

v0.7 creates:
- `/tamapoke_v7_a.bin`
- `/tamapoke_v7_b.bin`

## Firmware

Attach `TamaPoke-CardputerADV-v0.7-MERGED.bin` to this GitHub release.
